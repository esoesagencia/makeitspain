# MakeItSpain — Trip Plan Format

When Claude generates a trip plan, the output is a JSON block prefixed with MAKEITSPAIN_PLAN:
Paste the entire block into the AI Assistant chat. It executes directly — no AI interpretation, no errors.

## Format

MAKEITSPAIN_PLAN:
{
  "operations": [
    {
      "type": "update_trip",
      "fields": {
        "tripName": "...",
        "clientName": "...",
        "destination": "...",
        "numberOfPeople": 2,
        "tripType": "...",
        "budgetFrom": 0,
        "budgetTo": 0,
        "budgetMode": "per_trip",
        "specialRequirements": [],
        "personalMessage": "...",
        "additionalInfoClimate": "...",
        "additionalInfoDressCode": "...",
        "additionalInfoUsefulTips": "..."
      }
    },
    {
      "type": "add_accommodation",
      "tempId": "accom_1",
      "fields": {
        "type": "hotel",
        "name": "...",
        "address": "...",
        "contactPhone": "..."
      }
    },
    {
      "type": "add",
      "tempId": "act_1",
      "fields": {
        "title": "...",
        "category": "transfer|meal|activity|free_time|wellness_grooming|surprise",
        "date": "YYYY-MM-DD",
        "startTime": "HH:MM",
        "endTime": "HH:MM",
        "estimatedDuration": 60,
        "place": "...",
        "address": "...",
        "transferMode": "taxi|walking|transit",
        "isBooked": true,
        "contactPhone": "...",
        "contactLink": "...",
        "recommendations": "...",
        "coordinatorNote": "...",
        "isSurprise": false,
        "reminderEnabled": false,
        "reminderMinutesBefore": 30,
        "reminderMessage": "..."
      }
    }
  ]
}

## Notes
- nights are never included in add_accommodation — always auto-calculated from trip dates
- category "hotel" and "sleep_in_hotel" are never used — auto-generated by accommodation system
- Check-in cards → category: "activity"
- In-room breakfast → category: "meal"
- dates must be real YYYY-MM-DD strings (Day 1 = trip startDate, Day 2 = startDate+1, etc.)
